# 📂 data

All datasets used across both tracks of the COVID-19 Analysis project.

---

## Subfolders

| Folder | Purpose |
|--------|---------|
| `raw/` | Original unmodified source files — gitignored |
| `processed/` | Cleaned or transformed outputs generated by the notebooks |

## Two Independent Tracks

This project has two completely independent data tracks — you do not need SQL Server to run the Python notebooks, and you do not need Python to run the SQL queries.

| Track | Files Needed | Tool |
|-------|-------------|------|
| SQL exploration | `CovidDeaths.xlsx` + `covidvaccination.xlsx` | SQL Server / SSMS |
| Python forecasting | `covid.csv` only (featured.csv auto-generated) | Jupyter Notebook |
